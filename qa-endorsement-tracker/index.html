Setup & help

This tracker reads and writes a single SharePoint list so the whole NPD QA team edits one shared copy. Each "Endorsement of Tasks" handover is stored as one list item; all of its sections and its file references are kept as JSON in one text column, so list setup stays trivial.

SharePoint list: QAEndorsements

ColumnTypeNotes
TitleSingle line of textShift label, e.g. "2025-09-30 Night — Juan"
ShiftDateDate and Time (or ISO text)The shift date
ShiftChoice / single lineDay · Mid · Night
QAResourceSingle line of textQA who logged it
PayloadMultiple lines of plain textJSON.stringify({sections, fileRefs}) — all handover sections plus the "Needs Continuation Test File Upload" references (links, SharePoint attachments, or inline demo files)

Connect it

Upload index.html to a document library (e.g. Site Assets) and surface it via a File Viewer / Embed / Content Editor web part, or link to it as a page. When the page is served from SharePoint it auto-detects the site from the page context. If auto-detect does not apply, set SP_CONFIG.siteUrl near the top of the file. Full steps are in SETUP.md next to this file.

Permissions

List Contribute = can log and edit endorsements. Read = view only.

Demo vs connected

Connected mode reads and writes the live list. Demo mode (no site context) uses sample data saved to this browser so you can preview the tool anywhere; it is clearly labelled and never touches SharePoint.
