Setup & help

This tracker reads and writes a single Google Sheet so the whole NPD QA team edits one shared copy. The page is served by a container-bound Google Apps Script Web App; each "Endorsement of Tasks" handover is stored as one row, with all of its sections and file references kept as JSON in one Payload cell, so sheet setup stays trivial.

Connect it

Create a Google Sheet, open Extensions › Apps Script, paste Code.gs, add an HTML file named index with this page, paste appsscript.json, then Deploy › New deployment › Web app (Execute as Me). Share the Web App URL with the team. Full steps are in README.md next to this file.

Slack & reminders

Posting is server-side: saving a new endorsement auto-posts a Slack alert (set SLACK_WEBHOOK_URL in Script Properties). A native time-trigger reminds the team of any open Urgent/High Prio AXOs at each shift start (run setupShiftReminders once).

Demo vs connected

Connected mode reads and writes the live Sheet. Demo mode (opened outside Apps Script) uses sample data saved to this browser so you can preview the tool anywhere; it is clearly labelled and never touches the Sheet.
